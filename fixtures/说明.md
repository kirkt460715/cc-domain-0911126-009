# 合成数据字段

material_runs.jsonl 含温度、压力和强度观测，batch 是独立试验批次，center_repeat 标示中心条件。material_schema.json 可用 schema 动作登记，随后使用 register 和 ingest 导入。数值为十进制文本。

rsm_schema.json 与下列合成文件用于响应面研究测试：rsm_interior_peak.jsonl（内部峰值）、rsm_boundary_peak.jsonl（边界峰值）、rsm_extrapolation.jsonl（因子盒内但设计点凸包外的推荐）、rsm_collinear.jsonl（共线设计）、rsm_three_factor.jsonl（三因子完整二次设计）、rsm_no_replication.jsonl（无独立重复）和 rsm_ambiguous_peak.jsonl（批次重采样时最优点换边界）。每个条件下 batch-0/1/2 是独立试验批次，center_repeat 标示中心条件重复。
